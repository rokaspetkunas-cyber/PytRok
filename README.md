# PytRok

Internetinis puslapis apie muzikos pamokas, sukurtas su „Flask“.

## Kaip paleisti

1. Įdiek priklausomybes:
   ```bash
   pip install flask
   ```
2. Paleisk serverį:
   ```bash
   python app.py
   ```
3. Naršyklėje atverk [http://localhost:5000](http://localhost:5000) ir pasidairyk po pamokų pasiūlymus.

## Puslapio turinys

- Informacija apie populiariausias pamokas.
- Mokytojų komandos pristatymas.
- Kontaktų skiltis su registracijos forma.
